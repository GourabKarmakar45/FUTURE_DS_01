# Git Setup and Push to GitHub Repo (FUTURE_DS_01)

## Steps:
- [x] 1. `git init` - Initialize Git repository.
- [ ] 2. `git add .` - Stage all files.
- [ ] 3. `git commit -m "Initial commit: complete sales analysis project with Python analysis, PowerBI dashboard, charts, and report."` - Commit staged files.
- [ ] 4. `git remote add origin https://github.com/GourabKarmakar45/FUTURE_DS_01.git` - Add remote.
- [ ] 5. `git branch -M main` - Rename branch to main.
- [ ] 6. `git push -u origin main --force-with-lease` - Force push (safe) to overwrite empty remote repo.
- [ ] 7. Clean up: Remove cloned dir `rmdir /s /q FUTURE_DS_01` (Windows).
- [ ] 8. Verify: `git status` and `git remote -v`.

**Notes:** Uses --force-with-lease for safety. Repo will now contain the full current project.
